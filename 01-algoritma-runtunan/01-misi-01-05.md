# 👋 Misi 1 — Program Pertamaku

## Cerita

Hari ini adalah hari pertamamu sebagai siswa di **CodeVille Academy**. Sebagai tradisi, setiap calon programmer diminta membuat program pertama yang menampilkan sebuah pesan sederhana di layar. Walaupun terlihat sangat mudah, hampir semua programmer di dunia pernah memulai dari program ini.

## Tugas

Sekarang giliranmu membuat program pertama.

Buatlah sebuah program yang menampilkan tulisan berikut pada layar.

```text
Hello World!
```

## Challenge

Ubah program agar menampilkan namamu pada baris berikutnya.

## Tahukah Kamu?

💡 Program **Hello World** sudah digunakan selama puluhan tahun sebagai latihan pertama saat mempelajari bahasa pemrograman baru.

# 🤖 Misi 2 — Penghitung Total Poin Robot

## Cerita

Sekolah sedang mengadakan pertandingan robot. Robot Merah dan Robot Biru berhasil mengumpulkan sejumlah poin. Guru ingin mengetahui total poin kedua robot dengan cepat sehingga tidak perlu menghitungnya secara manual.

## Tugas

Sekarang giliranmu membantu guru.

Buatlah program yang dapat:

- meminta pengguna memasukkan poin Robot Merah;

- meminta pengguna memasukkan poin Robot Biru;

- menghitung total poin kedua robot;

- menampilkan hasil perhitungannya.

## Contoh Penggunaan

```text
Masukkan poin Robot Merah : 10
Masukkan poin Robot Biru  : 9

Total poin kedua robot adalah 19.
```

# 🌳 Misi 3 — Menghitung Luas Kolam

## Cerita

Taman Kota CodeVille akan membangun sebuah kolam berbentuk lingkaran. Petugas taman meminta bantuanmu menghitung luas kolam menggunakan nilai π = **3.14159**.

## Tugas

Sekarang giliranmu membantu petugas taman.

Buatlah program yang dapat:

- meminta pengguna memasukkan jari-jari kolam;

- menghitung luas kolam;

- menampilkan hasil dengan 4 angka di belakang koma.

## Contoh Penggunaan

```text
Masukkan jari-jari kolam : 2

Luas kolam = 12.5664
```

# 📚 Misi 4 — Total Buku Baru

## Cerita

Perpustakaan CodeVille menerima kiriman buku baru selama dua hari. Petugas ingin mengetahui jumlah seluruh buku yang diterima.

## Tugas

Sekarang giliranmu membantu petugas perpustakaan.

Buatlah program yang dapat:

- meminta jumlah buku hari pertama;

- meminta jumlah buku hari kedua;

- menghitung total buku;

- menampilkan hasilnya.

## Contoh Penggunaan

```text
Jumlah buku hari pertama : 30
Jumlah buku hari kedua   : 10

Total buku = 40
```

# 🖨️ Misi 5 — Menghitung Luas Banner

## Cerita

Sebuah percetakan ingin menghitung luas banner berbentuk persegi panjang sebelum proses pencetakan dimulai.

## Tugas

Sekarang giliranmu membantu pemilik percetakan.

Buatlah program yang dapat:

- meminta panjang banner;

- meminta lebar banner;

- menghitung luas banner;

- menampilkan hasilnya.

## Contoh Penggunaan

```text
Masukkan panjang banner : 3
Masukkan lebar banner   : 9

Luas banner = 27
```
