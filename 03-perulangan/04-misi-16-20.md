# Bab 3 — Perulangan

## Misi 16–20

Pada misi sebelumnya, kamu sudah menggunakan perulangan untuk memproses data dan melakukan perhitungan. Sekarang kita akan mulai menggunakan **perulangan bertingkat** dan pola perulangan yang lebih kompleks.

# 🏭 Misi 16 — Pola Pemeriksaan Mesin

## Cerita

Sebuah pabrik memiliki sistem pemeriksaan otomatis. Mesin melakukan pemeriksaan secara bertahap dengan dua nilai yang berubah pada setiap proses.

Temukan pola `I` dan `J` pada sistem.

Sistem harus terus menampilkan pasangan nilai tersebut sampai nilai `J` mencapai `0`.

## Tugas

Buatlah program yang menghasilkan pola berikut:

```text
I=1 J=60
I=4 J=55
I=7 J=50
...
```

Perulangan harus berhenti ketika nilai `J` mencapai `0`.

## Contoh Hasil

Bagian awal:

```text
I=1 J=60
I=4 J=55
I=7 J=50
I=10 J=45
```

Bagian akhir:

```text
I=34 J=5
I=37 J=0
```

# 🎮 Misi 17 — Kombinasi Level dan Hadiah

## Cerita

Sebuah game memiliki beberapa level. Pada setiap level, pemain bisa mendapatkan tiga jenis hadiah dengan nilai `7`, `6`, dan `5`.

Level pertama menggunakan nilai tersebut secara berurutan:

```text
I=1 J=7
I=1 J=6
I=1 J=5
```

Setelah semua hadiah pada level pertama selesai diperiksa, game berpindah ke level berikutnya. Temukan pola I nya!


## Tugas

Buatlah program yang menghasilkan seluruh kombinasi level dan hadiah berikut:

```text
I=1 J=7
I=1 J=6
I=1 J=5
I=3 J=7
I=3 J=6
I=3 J=5
...
I=9 J=7
I=9 J=6
I=9 J=5
```

## Challenge

Coba ubah program sehingga setiap level memiliki **5 jenis hadiah**.

# 🤖 Misi 18 — Jadwal Robot

## Cerita

Sebuah robot gudang bekerja berdasarkan kombinasi antara **nomor zona** dan **waktu pemeriksaan**.

Zona robot bernomor `1`, `3`, `5`, `7`, dan `9`.

Untuk setiap zona, robot melakukan pemeriksaan pada tiga waktu berbeda. Pada zona pertama, waktunya adalah `7`, `6`, dan `5`. Ketika robot berpindah ke zona berikutnya, ketiga waktu tersebut bertambah **2**.

Dengan demikian:

```text
I=1 J=7
I=1 J=6
I=1 J=5

I=3 J=9
I=3 J=8
I=3 J=7
```

dan seterusnya.

## Tugas

Buatlah program yang menghasilkan seluruh jadwal pemeriksaan robot:

```text
I=1 J=7
I=1 J=6
I=1 J=5
I=3 J=9
I=3 J=8
I=3 J=7
...
I=9 J=15
I=9 J=14
I=9 J=13
```

Perhatikan bahwa setiap zona memiliki **3 waktu pemeriksaan**.

# 🧪 Misi 19 — Jadwal Pengujian Laboratorium

## Cerita

Sebuah laboratorium menggunakan sistem penjadwalan otomatis. Setiap sesi pengujian memiliki nilai `I`, sedangkan setiap pengujian dalam sesi tersebut memiliki nilai `J`.

Nilai `I` dimulai dari `0` dan bertambah **0.2** setiap sesi.

Untuk setiap nilai `I`, laboratorium melakukan tiga pengujian:

```text
J = I + 1
J = I + 2
J = I + 3
```

Contohnya, ketika `I = 0`:

```text
I=0 J=1
I=0 J=2
I=0 J=3
```

Kemudian ketika `I = 0.2`:

```text
I=0.2 J=1.2
I=0.2 J=2.2
I=0.2 J=3.2
```

Proses berlanjut hingga `I = 2`.

## Tugas

Buatlah program yang menampilkan seluruh jadwal pengujian tersebut.

Format hasil harus mengikuti pola:

```text
I=0 J=1
I=0 J=2
I=0 J=3
I=0.2 J=1.2
I=0.2 J=2.2
I=0.2 J=3.2
...
I=2 J=?
I=2 J=?
I=2 J=?
```

Perhatikan bahwa nilai desimal harus ditampilkan dengan format yang sesuai.

# ➕ Misi 20 — Menjumlahkan Nomor Ganjil dari Banyak Kasus

## Cerita

Sebuah aplikasi analisis angka menerima beberapa pasangan angka sekaligus. Untuk setiap pasangan, aplikasi harus mencari seluruh **bilangan ganjil yang berada di antara kedua angka tersebut**, tanpa memasukkan angka batasnya.

Misalnya diberikan:

```text
4 5
```

Tidak ada bilangan ganjil yang berada di antara `4` dan `5`, sehingga hasilnya `0`.

Sedangkan untuk:

```text
13 10
```

bilangan yang berada di antara keduanya adalah:

```text
11
```

sehingga hasilnya `11`.

Program harus melakukan proses tersebut untuk semua pasangan angka yang diberikan.

## Tugas

Buatlah program yang dapat:

* membaca jumlah kasus;
* membaca dua bilangan untuk setiap kasus;
* mencari bilangan ganjil yang berada di antara kedua bilangan tersebut;
* menjumlahkan seluruh bilangan ganjil tersebut;
* menampilkan hasil untuk setiap kasus.

## Contoh Penggunaan

Input:

```text
7

4 5
13 10
6 4
3 3
3 5
3 4
3 8
```

Output:

```text
0
11
5
0
0
0
12
```

## Challenge

Coba buat program tanpa mengubah urutan angka yang diberikan. Artinya, program harus tetap bekerja ketika angka pertama lebih besar maupun lebih kecil dari angka kedua.

## 🚀 Tantangan Bab 3

Kamu sekarang sudah menggunakan perulangan untuk beberapa pola yang berbeda:

* mengulang sejumlah angka;
* menghitung data;
* mencari nilai tertentu;
* membuat pola angka;
* melakukan perulangan di dalam perulangan;
* memproses banyak kasus.

Mulai dari sini, perhatikan satu hal penting:

> **Ketika sebuah pekerjaan harus dilakukan berkali-kali, pikirkan apakah perulangan dapat mengambil alih pekerjaan tersebut.**
