# Bab 3 — Perulangan
## Misi 1–5

Pada bab sebelumnya, program hanya menjalankan instruksi satu kali atau mengambil keputusan berdasarkan suatu kondisi. Pada bab ini, kamu akan belajar **perulangan (looping)**, yaitu menjalankan instruksi yang sama secara berulang tanpa harus menulis kode yang sama berkali-kali.

Perulangan sangat sering digunakan dalam dunia pemrograman, misalnya untuk memproses daftar siswa, menghitung transaksi, membaca data sensor, hingga membuat animasi pada game.

---

# 🚦 Misi 1 — Menyalakan Lampu Jalur Genap

## Cerita

Sebuah stadion baru sedang diuji sebelum digunakan untuk pertandingan. Di sepanjang jalur stadion terdapat lampu yang diberi nomor dari **1 hingga 100**.

Agar teknisi lebih mudah melakukan pengecekan, hanya lampu dengan **nomor genap** yang harus dinyalakan.

Bantulah teknisi membuat program untuk menampilkan seluruh nomor lampu yang harus menyala.

## Tugas

Buatlah program yang dapat:

- menampilkan seluruh bilangan genap dari **1 sampai 100**;
- setiap bilangan ditampilkan pada baris yang berbeda.

## Contoh Penggunaan

```text
2
4
6
...
100
```

# 🌡️ Misi 2 — Menghitung Sensor yang Aktif

## Cerita

Sebuah stasiun cuaca memiliki enam sensor. Setelah dilakukan pemeriksaan, setiap sensor mengirimkan satu nilai.

- Nilai **positif** berarti sensor bekerja dengan baik.
- Nilai **negatif** berarti sensor mengalami gangguan.

Tugasmu adalah menghitung berapa banyak sensor yang masih berfungsi dengan baik.

## Tugas

Buatlah program yang dapat:

- membaca **6 buah bilangan**;
- menghitung berapa banyak bilangan yang bernilai positif;
- menampilkan jumlahnya.

## Contoh Penggunaan

```text
Data sensor 1 : 7
Data sensor 2 : -5
Data sensor 3 : 6
Data sensor 4 : -3.4
Data sensor 5 : 4.6
Data sensor 6 : 12

Sensor aktif : 4
```

## Challenge

Hitung juga berapa banyak sensor yang mengalami gangguan.

# 🎫 Misi 3 — Membagi Nomor Peserta

## Cerita

Sebuah lomba pemrograman memiliki lima peserta yang masing-masing mendapatkan nomor peserta.

Panitia ingin membagi peserta menjadi dua kelompok.

- Nomor **genap** masuk ke **Kelompok A**.
- Nomor **ganjil** masuk ke **Kelompok B**.

Tugasmu adalah menghitung berapa banyak peserta yang masuk ke Kelompok A.

## Tugas

Buatlah program yang dapat:

- membaca **5 nomor peserta**;
- menghitung jumlah nomor yang genap;
- menampilkan hasilnya.

## Contoh Penggunaan

```text
Nomor peserta

7
-5
6
-4
12

Peserta Kelompok A : 3
```

## Challenge

Hitung juga jumlah peserta yang masuk ke Kelompok B.

# 📊 Misi 4 — Analisis Data Server

## Cerita

Sebuah server mencatat lima buah nilai log yang nantinya akan dianalisis oleh administrator.

Administrator ingin mengetahui:

- berapa banyak nilai genap;
- berapa banyak nilai ganjil;
- berapa banyak nilai positif;
- berapa banyak nilai negatif.

Program harus menghitung seluruh kategori tersebut dalam satu proses.

> **Catatan**
>
> Nilai **0** termasuk bilangan genap, tetapi **bukan** bilangan positif maupun negatif.

## Tugas

Buatlah program yang dapat:

- membaca **5 bilangan bulat**;
- menghitung jumlah bilangan genap;
- menghitung jumlah bilangan ganjil;
- menghitung jumlah bilangan positif;
- menghitung jumlah bilangan negatif;
- menampilkan seluruh hasil.

## Contoh Penggunaan

```text
Data

-5
0
-3
-4
12

Bilangan genap    : 3
Bilangan ganjil   : 2
Bilangan positif  : 1
Bilangan negatif  : 3
```

## Challenge

Hitung juga jumlah seluruh bilangan yang dimasukkan.

## Tahukah Kamu?

💡 Sistem monitoring server sungguhan sering melakukan proses serupa untuk menganalisis ribuan data log setiap detik.

# 🪑 Misi 5 — Menandai Nomor Kursi

## Cerita

Sebuah gedung pertunjukan menggunakan nomor kursi mulai dari **1** hingga **X**.

Untuk mempermudah petugas, hanya kursi dengan **nomor ganjil** yang akan diberi tanda khusus.

Buatlah program yang dapat menampilkan seluruh nomor kursi yang harus diberi tanda.

## Tugas

Buatlah program yang dapat:

- membaca sebuah bilangan bulat **X**;
- menampilkan seluruh bilangan ganjil dari **1 hingga X**;
- setiap bilangan ditampilkan pada baris yang berbeda.

## Contoh Penggunaan

```text
Nomor kursi terakhir : 8

1
3
5
7
```
