### Batch 1 (Misi 1--5)

Selamat datang di **CodeVille Academy**!

Di kota kecil bernama **CodeVille**, kamu adalah seorang programmer muda
yang siap membantu banyak orang menyelesaikan masalah menggunakan

# Misi 1 --- Program Pertamaku 👋

## Cerita

Hari ini adalah hari pertamamu belajar pemrograman di CodeVille Academy.

Sebagai tradisi, setiap programmer baru harus membuat program pertama
yang menampilkan sebuah pesan sambutan.

## Tugas

Buatlah program yang menampilkan tulisan:

`Hello World!`

### Contoh Output

``` text
Hello World!
```

# Misi 2 --- Penghitung Total Poin Robot 🤖

## Cerita

Sekolah mengadakan pertandingan robot.

Robot Merah dan Robot Biru berhasil mengumpulkan poin. Guru ingin
mengetahui jumlah poin keduanya.

## Tugas

Buatlah program yang: 
- meminta pengguna memasukkan poin Robot Merah.
- meminta pengguna memasukkan poin Robot Biru.
- menampilkan total poin kedua robot.

### Contoh

``` text
=== Penghitung Poin Robot ===

Masukkan poin Robot Merah : 10
Masukkan poin Robot Biru  : 9

Total poin kedua robot adalah 19.
```

# Misi 3 --- Menghitung Luas Kolam 🌳

## Cerita

Di taman CodeVille akan dibuat sebuah kolam berbentuk lingkaran.

Petugas taman sudah mengetahui jari-jari kolam, tetapi belum mengetahui
luasnya.

Gunakan π = **3.14159**.

## Tugas

Buatlah program yang: - meminta jari-jari kolam; - menghitung luas
kolam; - menampilkan hasil dengan **4 angka di belakang koma**.

### Contoh

``` text
=== Menghitung Luas Kolam ===

Masukkan jari-jari kolam : 2

Luas kolam = 12.5664
```

# Misi 4 --- Total Buku Baru 📚

## Cerita

Perpustakaan CodeVille menerima kiriman buku selama dua hari.

Petugas ingin mengetahui jumlah seluruh buku yang diterima.

## Tugas

Buatlah program yang: - meminta jumlah buku hari Senin; - meminta jumlah
buku hari Selasa; - menampilkan total buku.

### Contoh

``` text
=== Total Buku Baru ===

Jumlah buku hari Senin : 30
Jumlah buku hari Selasa: 10

Total buku = 40
```

# Misi 5 --- Menghitung Luas Banner 🖨️

## Cerita

Sebuah percetakan akan mencetak banner berbentuk persegi panjang.

Pemilik ingin mengetahui luas banner sebelum proses pencetakan dimulai.

## Tugas

Buatlah program yang: - meminta panjang banner; - meminta lebar
banner; - menghitung luas banner; - menampilkan hasilnya.

### Contoh

``` text
=== Menghitung Luas Banner ===

Masukkan panjang : 3
Masukkan lebar   : 9

Luas banner = 27
```
