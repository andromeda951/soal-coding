# Bab 2 — Percabangan
## Misi 1–5

Pada bab sebelumnya, setiap program selalu menjalankan instruksi secara berurutan dari awal hingga akhir. Pada bab ini, kamu akan belajar membuat program yang **dapat mengambil keputusan** menggunakan **percabangan (`if`, `else if`, dan `else`)**.

Dalam kehidupan sehari-hari, hampir semua aplikasi menggunakan percabangan. Misalnya, aplikasi kasir menentukan harga berdasarkan menu yang dipilih, aplikasi sekolah menentukan kelulusan siswa berdasarkan nilai, atau aplikasi navigasi memberikan peringatan berdasarkan kondisi tertentu.

# ✅ Misi 1 — Validasi Data Pendaftaran

## Cerita

CodeVille Academy sedang membuka pendaftaran untuk kelas pemrograman tingkat lanjut. Sebelum data peserta disimpan ke dalam sistem, aplikasi harus memastikan bahwa data yang dimasukkan sudah memenuhi seluruh persyaratan.

Sebuah data dianggap **valid** jika memenuhi semua kondisi berikut.

- Nilai **B** lebih besar dari **C**.
- Nilai **D** lebih besar dari **A**.
- Jumlah **C + D** lebih besar daripada **A + B**.
- Nilai **C** dan **D** harus lebih besar dari **0**.
- Nilai **A** harus merupakan bilangan genap.

Jika seluruh syarat terpenuhi, tampilkan bahwa data diterima. Jika ada satu saja syarat yang tidak terpenuhi, tampilkan bahwa data ditolak.

## Tugas

Buatlah program yang dapat:

- meminta empat buah bilangan bulat (**A**, **B**, **C**, dan **D**);
- memeriksa seluruh persyaratan;
- menampilkan hasil validasi.

## Contoh Penggunaan

```text
Masukkan A : 2
Masukkan B : 3
Masukkan C : 2
Masukkan D : 6

Data diterima.
```

## Challenge

Tambahkan informasi mengenai syarat mana yang tidak terpenuhi.

# 🧮 Misi 2 — Kalkulator Persamaan Kuadrat

## Cerita

Seorang siswa sedang membuat aplikasi matematika yang dapat menghitung akar-akar persamaan kuadrat.

Persamaan kuadrat memiliki bentuk:

```text
ax² + bx + c = 0
```

Gunakan rumus berikut.

```text
          -b + √(b² - 4ac)
x₁ = -------------------------
               2a

          -b - √(b² - 4ac)
x₂ = -------------------------
               2a
```

Perhitungan hanya dapat dilakukan jika:

- nilai **a** tidak sama dengan **0**;
- nilai **b² − 4ac** tidak negatif.

Jika salah satu syarat tidak terpenuhi, tampilkan bahwa akar tidak dapat dihitung.

## Tugas

Buatlah program yang dapat:

- meminta nilai **a**, **b**, dan **c**;
- menentukan apakah akar dapat dihitung;
- menampilkan kedua akar jika memungkinkan.

## Contoh Penggunaan

```text
Masukkan a : 10
Masukkan b : 20.1
Masukkan c : 5.1

Akar pertama : -0.29788
Akar kedua   : -1.71212
```

# 🌡️ Misi 3 — Kategori Suhu Server

## Cerita

Sebuah ruang server memiliki sistem pemantauan suhu otomatis. Agar teknisi lebih mudah membaca kondisi server, suhu akan dikelompokkan ke dalam beberapa rentang.

Gunakan kategori berikut.

- **[0, 25]**
- **(25, 50]**
- **(50, 75]**
- **(75, 100]**

Jika suhu berada di luar rentang tersebut, tampilkan bahwa suhu berada di luar interval.

## Tugas

Buatlah program yang dapat:

- meminta nilai suhu;
- menentukan interval suhu;
- menampilkan hasilnya.

## Contoh Penggunaan

```text
Masukkan suhu : 25.01

Suhu berada pada interval (25, 50]
```

# 🎓 Misi 5 — Menentukan Status Kelulusan

## Cerita

Setelah ujian semester selesai, sekolah ingin membuat sistem yang dapat menentukan status setiap siswa secara otomatis.

Status siswa ditentukan berdasarkan nilai rata-rata.

- Nilai **7,0 atau lebih** → **Lulus**
- Nilai **kurang dari 5,0** → **Tidak Lulus**
- Nilai **antara 5,0 hingga 6,9** → **Ujian Perbaikan**

Jika siswa mengikuti ujian perbaikan, program akan meminta nilai ujian tersebut. Nilai akhir baru diperoleh dari rata-rata nilai sebelumnya dengan nilai ujian perbaikan.

Jika nilai akhir baru **minimal 5,0**, siswa dinyatakan lulus.

## Tugas

Buatlah program yang dapat:

- meminta empat nilai siswa;
- menghitung nilai akhir menggunakan bobot yang diberikan;
- menentukan status siswa;
- jika diperlukan, meminta nilai ujian perbaikan;
- menghitung nilai akhir setelah ujian perbaikan;
- menampilkan status akhir siswa.

## Contoh Penggunaan

```text
Nilai Biologi    : 60
Nilai Fisika     : 50
Nilai Matematika : 85
Nilai Sejarah    : 40

Rata-rata : 58.75
Status    : Ujian Perbaikan

Nilai ujian perbaikan : 70

Status akhir : Lulus
Nilai akhir  : 64.37
```

## Tahukah Kamu?

💡 Sistem informasi akademik di sekolah dan universitas menggunakan proses serupa untuk menentukan status kelulusan mahasiswa secara otomatis.
